--- title: "LLM 모델 파일의 정체는?" date: "2026-11-06" ---

LLM(대규모 언어 모델)은 결국 거대한 '데이터 파일' 형태로 존재하며, 이를 서버나 PC에 복사(설치)하여 실행하는 구조이다.


1. LLM 모델 파일이란 무엇인가?

  • 수조(조 단위) 개의 숫자(파라미터/Weights)가 저장된 거대한 데이터 파일

  • 파일 확장자: .bin, .safetensors, .gguf (양자화 버전) 등

    • 양자화(Quantization) 기법을 적용하면 14GB짜리 7B 모델을 4GB 수준으로 압축해서 일반 PC에서도 돌릴 수 있다.
  • 크기: 모델의 크기(파라미터 수)에 따라 파일 용량이 매우 크다.
    • 예: 7B(70억 파라미터) 모델은 약 4GB~14GB
    • 예: 70B(700억 파라미터) 모델은 약 40GB~140GB 이상

비유하자면,

  • LLM 모델 파일은 '뇌'에 해당한다.
  • 이 파일 안에 '문장 A 뒤에 B가 올 확률'과 같은 수학적 패턴이 모두 저장되어 있다.
  • 이 파일만으로는 아무것도 하지 못한다.
  • '뇌'만 따로 떼어놓은 상태이므로, 이 뇌를 처리할 수 있는 '몸체(추론 엔진)'가 필요하다.

2. 추론 엔진이란 어떤 '파일'인가?


추론 엔진 (Inference Engine)은 모델 파일(뇌)을 읽어들이고, 사용자가 입력한 텍스트를 처리하여 답변을 생성하는 소프트웨어이다.

  • 실행 가능한 소프트웨어(Executable) 또는 라이브러리

  • 형식

    • 실행 파일 (Binary): ollama, llama.cpp의 컴파일된 바이너리 등. 운영체제(Windows/Linux)에서 직접 실행되는 프로그램
    • 라이브러리 (Library): Python의 transformers, vllm 모듈 등. 개발자가 코드를 작성하여 호출하는 소프트웨어 부품
    • 컨테이너 이미지 (Docker Image): vllm, TGI 등은 보통 Docker 컨테이너 형태로 배포되어, 서버에서 격리된 환경으로 실행

  • 역할

    • 모델 파일(Weights)을 메모리(RAM/GPU VRAM)에 올린다.
    • 사용자가 입력한 텍스트를 수학적으로 처리한다.
    • 생성된 답변을 출력한다.
    • 추론 엔진은 모델 파일을 "실행"시키는 인터프리터(Interpreter) 또는 런타임(Runtime) 역할을 한다.

3. LLM을 '설치'하고 실행하는 과정


LLM을 로컬(내 컴퓨터나 사내 서버)에서 돌리려면 LLM 모델 파일, 추론엔진 파일이 필요하다.

  1. 추론 엔진 설치: (예: Ollama 설치)
  2. 모델 다운로드/복사: (예: ollama pull llama3 명령어 실행 또는 모델 파일 복사)
    • 이 단계에서 모델 파일이 내 컴퓨터의 특정 폴더(예: C:\Users\...\ollama\models)에 저장된다.
  3. 실행: 엔진이 모델 파일을 로드하여, 이제 사용자의 질문에 답변할 준비가 완료된다.

4. 클라우드 LLM과 로컬 LLM의 차이 (파일 관점에서)


  • 클라우드 LLM (ChatGPT, Claude 등):
    • 모델 파일은 벤더(OpenAI, Anthropic)의 서버에 저장되어 있다.
    • 우리는 파일을 설치하지 않고, 인터넷을 통해 벤더의 서버에 요청을 보내고 답변을 받아온다.
    • 따라서 내 컴퓨터에는 모델 파일이 없으며, 인터넷 연결이 필수이다.
  • 로컬 LLM (Llama, Mistral 등):
    • 모델 파일이 내 컴퓨터나 사내 서버에 저장되어 있다.
    • 인터넷 연결 없이도, 내 하드웨어(GPU)를 이용해 모델 파일을 직접 처리한다.
    • 데이터가 외부로 나가지 않아 보안이 높고, 인터넷이 끊겨도 작동한다.
    • 고성능 GPU(그래픽 카드)가 필요하며, 모델 파일 용량이 커 저장 공간과 메모리가 많이 필요하다.

LLM 모델은 "설치"보다는 "모델 파일을 내 환경에 가져와서 실행 엔진에 연결하는 과정"에 가깝다.

이 파일이 내 서버에 존재하는 한, 내 서버가 그 AI의 두뇌 역할을 하게 되는 것이다.
